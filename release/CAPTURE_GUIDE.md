# CurseForge media capture

Capture the installed 1.0 build before publishing it. The old beta settings panel has a different layout.

1. Log into the Paladin in a safe, quiet location. Close chat conversations and menus that reveal private information.
2. Type `/ptk`. Capture the Overview and Ability timers pages with the new logo visible.
3. Choose Appearance. Keep Light effects on and Reduced motion off for the animated example, at your normal UI scale.
4. Click Preview HUD, close settings, then click Notes to open the sample note ribbon. The PREVIEW label must remain visible. No party chat is sent.
5. Capture a clean full-resolution screenshot and a short animation of this preview. Label it **In-game preview mode**, not combat footage.
6. End preview before demonstrating a real pull. In a dungeon party, obtain leadership, select an elite, and capture the selected-target Skull and engaged Cross behavior. Never stage marks on unrelated packs.

Suggested gallery:

- `01-settings.png` — refreshed Overview panel.
- `02-ability-timers.png` — individual timer controls.
- `03-hud-preview.png` — actual in-game preview rail and notes.
- `04-dungeon-marking.png` — a genuine dungeon example, if available.
- `05-hud-preview.gif` — short, looping recording with the preview label visible.

Save finished, reviewed media in `release/media`. Browser mockups and AI-generated gameplay scenes must not be described as in-game screenshots. Record source/version and any crop or resize in `release/media/README.txt`.
